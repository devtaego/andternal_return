# ANTERNAL RETURN

> 개미(Ant)는 영원히 돌아온다. 온라인 게임 "이터널 리턴"의 이름을 패러디한 증권 로그라이크.

과거 실제 증시 구간 중 하나에 랜덤으로 떨어져서 살아남는 **증권 로그라이크 게임**입니다.
플레이 중에는 지금이 몇 년도인지 알 수 없고, 시대가 끝나면 정답과 함께 투자 성향을 진단합니다.

> 모토: 쉽게 게임 → 결과로 투자 성향 진단 → 랭킹으로 고수 투자 패턴 소개

## 실행

빌드 과정 없는 단일 HTML 파일입니다. `index.html`을 브라우저로 열면 바로 플레이할 수 있어요.

- PC 단축키: `Space` / `Enter` = 다음 주

## 게임 규칙

- 1판 = 과거 실제 시대 하나(랜덤), 30주. 시작 자금 ₩10,000,000. 스테이지 없음
- 매주 시장 지수(x1) · 레버리지(x2) · 인버스(x-1)와 **그 시대 실존 기업 3곳**(가명으로 등장)을 사고팔기
- **정보상** (런닝맨 "투자의 귀재들" 방식): 매주 단계별로 정보 구매
  - 1단계 업계 소문: 어느 기업 이야기인지 + 방향 (정확도 60%, 자산의 0.5%)
  - 2단계 기자의 특종: 실제 그 시대 기사 헤드라인 (정확도 80%, 자산의 1.5%)
  - 3단계 내부자 쪽지: 다음 주 정확한 등락률 (100%, 자산의 4%)
- 지난주 기업 뉴스가 차트 아래 티커로 흘러감 (실제 호재·악재 기반)
- 자산이 원금의 40% 아래로 떨어지면 깡통 (게임 오버)
- **회귀권**: 깡통이 나거나 한 주에 -10% 이상 맞았을 때만 발동. 1주 전으로 돌아가 그 주를 다시 플레이 (시작 1개)
- 10주 · 20주차 **보급 상자**: 퍼크 카드 3장 중 1장 선택 (일반 / 희귀 / 전설)
- 콤보, 랜덤 이벤트 7종 (급등주 도박, 빚투, 앱 먹통, 유튜버 라이브, 정보상 쿠폰 등)
- 끝나면 몇 년도였는지 맞히기 (정답 시 +3%)
- **랭킹 = 시장 대비 초과수익(%p)**. 어떤 시대에 걸렸는지와 상관없이 공정하게 비교

## 끝난 뒤

1. 정답 공개 (어떤 시대였는지) + 가명 기업의 실명과 실제 스토리
2. 리플레이: 실제 차트 위에 내 매수·매도 타점과 실제 사건 표시
3. 고수 비교: 같은 구간을 존버 / 적립식 / 역발상 / 현금 전략으로 돌렸을 때 결과
4. 투자 성향 7유형 + 판단 근거 (불나방 개미, 존버 장인, 다람쥐 현금러, 단타 번개, 역발상 사냥꾼, 공포의 손절러, 정보 수집광)
5. 명예의 전당, 위기 도감

## 알아둘 점

- **지수·기업 차트는 근사치입니다.** 실제 주요 고점·저점과 사건을 기억에 의존해 잡고 30주로 압축했어요.
  큰 흐름은 실제와 비슷하고 잔파동은 매판 랜덤입니다. 발표 전에 실제 데이터로 바꾸는 것을 권장합니다 (`EPS` 배열의 `k`, `comps[].k`).
- 기업은 플레이 중 가명으로만 보이고, 끝난 뒤 실명을 공개합니다.
- 랭킹 · 도감 · 최고 기록은 브라우저 localStorage에만 저장됩니다 (다른 사람과 공유되지 않음).
- 그래픽 에셋(개미 캐릭터, 아이콘 21종, 도시 배경)은 코드 안의 픽셀아트 데이터(`SPR`, `ANT_BASE`)로 그립니다.
- 투자 성향 결과는 게임 내 행동을 바탕으로 한 재미용 분석이며 투자 권유가 아닙니다.

## 코드 구조 (`index.html`)

| 영역 | 내용 |
|---|---|
| `PAL`, `SPR`, `ANT_BASE`, `ANT_MOOD` | 픽셀아트 팔레트와 스프라이트 데이터 |
| `Scene` | 도시 배경 씬 (시장 흐름에 따라 날씨 · 하늘 변화, 개미 애니메이션) |
| `EPS` | 시대별 지수 키포인트 · 실제 사건 · 교훈 · 실존 기업(`comps`: 가명, 실명, 키포인트, 기사 이벤트, 스토리) |
| `genSeries` | 키포인트를 지나는 일별 지수 생성 (브라운 브리지 잔파동) |
| `nextWeek`, `trade`, `buyInfo`, `offerRewind`, `doRewind` | 핵심 게임 루프 · 정보상 · 회귀 |
| `PERKS`, `EVENTS` | 퍼크 · 랜덤 이벤트 정의 |
| `ghosts`, `personaOf`, `ending` | 고수 비교 · 성향 진단 · 엔딩 화면 |
