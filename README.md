# 개미 회귀록 (Ant Regression)

과거 실제 증시 구간 중 하나에 랜덤으로 떨어져서 살아남는 **증권 로그라이크 게임**입니다.
플레이 중에는 지금이 몇 년도인지 알 수 없고, 시대가 끝나면 정답과 함께 투자 성향을 진단합니다.

> 모토: 쉽게 게임 → 결과로 투자 성향 진단 → 랭킹으로 고수 투자 패턴 소개

## 실행

빌드 과정 없는 단일 HTML 파일입니다. `index.html`을 브라우저로 열면 바로 플레이할 수 있어요.

- PC 단축키: `Space` / `Enter` = 다음 주

## 게임 규칙

- 3개 스테이지(시대), 스테이지당 20주. 시작 자금 ₩10,000,000
- 매주 시장 지수(x1) · 레버리지(x2) · 인버스(x-1)를 사고팔기 (퍼크로 3배 레버리지 · 테마주 해금)
- 스테이지 목표: 시작 자산의 90% → 100% → 110% 이상. 미달하면 퇴출
- 자산이 원금의 40% 아래로 떨어지면 깡통 (게임 오버)
- **회귀권**: 깡통이 나거나 한 주에 -10% 이상 맞았을 때만 발동. 1주 전으로 돌아가 그 주를 다시 플레이 (시작 1개)
- 찌라시: 다음 주 방향 힌트, 신뢰도 60%
- 콤보: 3 · 5 · 8 · 12주 연속 수익이면 보너스
- 랜덤 이벤트 7종: 급등주 도박, 빚투, 앱 먹통, 유튜버 라이브 등
- 스테이지 사이에 퍼크 카드 3장 중 1장 선택 (일반 / 희귀 / 전설)
- 시대가 끝나면 몇 년도였는지 맞히기 (정답 시 +3%)

## 끝난 뒤

1. 정답 공개 (어떤 시대였는지)
2. 리플레이: 실제 차트 위에 내 매수·매도 타점과 실제 사건 표시
3. 고수 비교: 같은 구간을 존버 / 적립식 / 역발상 / 현금 전략으로 돌렸을 때 결과
4. 투자 성향 6유형 + 판단 근거 (불나방 개미, 존버 장인, 다람쥐 현금러, 단타 번개, 역발상 사냥꾼, 공포의 손절러)
5. 위기 도감, 명예의 전당, 성향 맞춤 다음 판 도전과제

## 수록 시대 (9개)

1998 IMF 이후 대반등 · 2000 닷컴 버블 붕괴 · 2008 글로벌 금융위기 · 2011 미국 신용등급 강등 ·
2015~16 박스피 · 2017 반도체 슈퍼사이클 · 2020 코로나 쇼크 · 2021~22 동학개미의 겨울 · 2024 여름 블랙먼데이

## 알아둘 점

- **차트 데이터는 근사치입니다.** 실제 지수의 주요 고점·저점을 기억에 의존해 잡고 20주로 압축했어요.
  큰 흐름은 실제와 같고 잔파동은 매판 랜덤입니다. 발표 전에 실제 지수 데이터로 바꾸는 것을 권장합니다 (`EPS` 배열의 `k` 키포인트).
- 랭킹 · 도감 · 최고 기록은 브라우저 localStorage에만 저장됩니다 (다른 사람과 공유되지 않음).
- 그래픽 에셋(개미 캐릭터, 아이콘 21종, 도시 배경)은 코드 안의 픽셀아트 데이터(`SPR`, `ANT_BASE`)로 그립니다.
- 투자 성향 결과는 게임 내 행동을 바탕으로 한 재미용 분석이며 투자 권유가 아닙니다.

## 코드 구조 (`index.html`)

| 영역 | 내용 |
|---|---|
| `PAL`, `SPR`, `ANT_BASE`, `ANT_MOOD` | 픽셀아트 팔레트와 스프라이트 데이터 |
| `Scene` | 도시 배경 씬 (시장 흐름에 따라 날씨 · 하늘 변화, 개미 애니메이션) |
| `EPS` | 시대별 키포인트 · 실제 사건 주석 · 교훈 |
| `genSeries` | 키포인트를 지나는 일별 지수 생성 (브라운 브리지 잔파동) |
| `nextWeek`, `trade`, `offerRewind`, `doRewind` | 핵심 게임 루프 |
| `PERKS`, `EVENTS` | 퍼크 · 랜덤 이벤트 정의 |
| `ghosts`, `personaOf`, `ending` | 고수 비교 · 성향 진단 · 엔딩 화면 |
